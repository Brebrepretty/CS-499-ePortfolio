# Enhancement One Narrative
## Software Design and Engineering

### Artifact Description

The artifact selected for this enhancement is my **Animal Shelter Dashboard** project that I originally created in **CS 340: Client/Server Development**.

The project is a Python Dash application connected to a MongoDB database that allows users to view animal shelter records, filter data, and display an animal's location on a map.

For this milestone, I enhanced the software design and engineering aspects of the application rather than simply preserving the original implementation.

---

### Why I Selected This Artifact

I selected this artifact because it demonstrates several software engineering skills in one project.

It combines:

- Python programming
- Database connectivity
- Data visualization
- User interaction
- CRUD operations

It also provided many opportunities to improve code quality, maintainability, reliability, and security.

These improvements make the project a stronger representation of my abilities for my professional ePortfolio.

---

### Enhancements Performed

For the software design and engineering enhancement, I:

- Refactored the CRUD module into a cleaner, object-oriented design.
- Added input validation for database operations.
- Improved exception handling.
- Added database connection verification.
- Added safer update and delete behavior.
- Improved code organization.
- Improved documentation and readability.
- Configured MongoDB and verified that the dashboard correctly loads and displays records and map data.

These changes made the application easier to understand, maintain, debug, and expand.

### Reflection

Completing this enhancement taught me much more than simply improving code.

I learned how to troubleshoot environment configuration issues, install and configure Python and MongoDB on a new computer, connect the dashboard to a live database, and verify that the application continued to function correctly after each change.

The biggest challenge was rebuilding the development environment and ensuring MongoDB, Dash, Jupyter, and Python all worked together.

Successfully overcoming these issues gave me a much better understanding of debugging, software configuration, and professional software engineering practices.

This enhancement also helped me understand that writing code that works is only the beginning. Professional software should also be maintainable, reliable, understandable, secure, and prepared for future changes.
