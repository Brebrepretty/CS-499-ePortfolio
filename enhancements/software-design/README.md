# Software Design and Engineering Enhancement

This folder contains the source code for **Enhancement One** of my CS 499 Computer Science Capstone.

## Focus of the Enhancement

This enhancement improved the software design and engineering of my **Animal Shelter Dashboard** through:

- Object-oriented design
- Improved CRUD functionality
- Input validation
- Exception handling
- Database connection verification
- Safer update and delete operations
- Improved code organization
- Improved documentation and readability
- Defensive programming practices
