# Database Enhancement

This folder contains the source code for **Enhancement Three** of my CS 499 Computer Science Capstone.

## Focus of the Enhancement

This enhancement improved the database functionality, security, and reliability of my **Animal Shelter Dashboard** through:

- Improved MongoDB connection management
- Environment-based database configuration
- Input validation
- Safer CRUD operations
- Improved query handling
- Database indexing
- Improved exception handling
- Protection of database credentials
- More secure and maintainable database access

## Technologies

- Python
- MongoDB
- PyMongo
- Dash
- pandas
- Jupyter Notebook

## Source Code

The source code files in this folder represent the enhanced version of the application developed for the Databases category.

The `.env.example` file demonstrates the environment variables required by the application without exposing private database credentials.
